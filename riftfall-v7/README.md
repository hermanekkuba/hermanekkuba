# RIFTFALL VII — Echoes of Guardians

Samostatná WebGL2 survival hra. Otevřete index.html nebo riftfall-v7.html v moderním prohlížeči. Bez instalace a externích závislostí.

- Přehled aktuálních vylepšení při výběru, kategorie a číselné porovnání před/po, rarity a synergie.
- Tři epické příšery během kola a závěrečný boss. Zlaté tokeny nabízejí Epic (80 %) nebo Legendary (20 %) upgrade. Nevyzvednuté odměny se nabídnou před dalším kolem.
- Sdílené modely a GPU instancing, prostorové vyhledávání kolizí, slučování XP se zachováním hodnoty, adaptivní rozlišení a optimalizované stíny.
- Detailnější 1024px procedurální materiály map. XP jsou modrofialové krystaly bez kruhového ohraničení.
- Původní ambientní hudba s přepínačem a hlasitostí. Spustí se po interakci uživatele.
- Upravené limity rychlosti útoku podle hrdiny, léčení, obrany, kritických zásahů a řetězových explozí.

WASD/šipky: pohyb; E: schopnost; mezerník: úskok; Esc: pauza/menu. Automatický základní útok.

Postup a achievementy se ukládají lokálně v prohlížeči; JSON export/import umožňuje přenos. Starší uložené hry jsou podporované. Vymazání dat webu odstraní místní postup.

Ověření: regresní a herní testy, prostorové kolize, ukládání, náhledy upgradů, zachování XP a nativní OpenGL ES test shaderů. Syntetický CPU benchmark sestavení zaplněné scény byl přibližně 39× rychlejší; nejde o měření FPS na uživatelově zařízení.
