# RIFTFALL

Samostatná fantasy survival aréna inspirovaná žánrem Swarm.

Druhá verze je ve větvi `riftfall-v2-3d`, ve složce `riftfall-v2`.

Pro spuštění stáhněte `riftfall-v2/riftfall-3d.html` a otevřete jej v aktuálním Chrome, Edge nebo Firefoxu. Bez instalace, serveru a internetového připojení. Vyžaduje WebGL 2.

Ovládání: WASD nebo šipky, mezerník pro úskok, E pro novu, Esc pro pauzu. Kolečko myši přibližuje kameru.

Vlastní grafika a postavy; nejde o oficiální produkt Riot Games.
